# Classroom Seating Organizer

A single, self-contained HTML file for planning a classroom seating chart: priorities near the
front, conflicts kept apart, good pairs kept close, with drag-and-drop, locks, undo/redo, print,
and JSON export/import. No install, no server, no external libraries.

**Live:** https://jannik-el.github.io/seating-organizer/

Or download `seating.html` and open it in a browser — it works offline. Data is stored in your
browser's localStorage only.

- Spec: [SPEC.md](SPEC.md)
- Tests: `node tests.mjs`
